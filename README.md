# App

Write your solution in `main.py`. It takes the log file path as its first argument.

---

## 🚀 How to Run

```bash
./run.sh app.log
```

---

## 🧪 Run Tests

Unit tests are located in `test_sample.py`. Add your own cases there to check your work.

```bash
./run_unittests.sh
```

---

## 🗂️ Project Structure

```
├── main.py             # Write your solution here
├── app.log             # Sample log file
├── test_sample.py      # Unit tests
├── run.sh              # Runs your solution against a log file
├── run_unittests.sh    # Runs all unit tests
└── README.md           # This file
```
